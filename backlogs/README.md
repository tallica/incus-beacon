# Backlogs

One file per idea that is too big for a line in [BACKLOG.md](../BACKLOG.md):
where it came from, why, what, what it needs from the maintainer, and what it
depends on. Start from [_template.md](_template.md) and name the file
`<kebab-idea>.md`.

When an idea is done, delete its file and its BACKLOG line; the commit and
CHANGELOG are the history. When it is rejected, delete the file and record it
under "Not planned" in [BACKLOG.md](../BACKLOG.md) with the reason.
